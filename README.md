# 32-bit-Single-Cycle-RISCV-ASIC-Flow-OpenLane2-SKY130
Complete RTL-to-GDSII implementation of a 32-bit Single-Cycle RISC-V processor using OpenLane 2, OpenROAD, Magic, Netgen and the Sky130 PDK. Includes synthesis, floorplanning, placement, CTS, routing, STA, power analysis, DRC, LVS and RTL optimization.
